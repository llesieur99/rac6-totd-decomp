# nonmatching

Useful attempts that do not match the retail bytes.

A file here is a kept piece of work, not a failure: it records what was
tried, where the bytes first differ, and what would make it worth another
attempt. Each one is indexed by the function it belongs to.

Every file states:

* the function and its measured address range;
* the source, as written;
* the first difference from the retail bytes (address, expected, got);
* the hypothesis that was being tested;
* the reopening condition: what would have to change for the attempt to be
  worth repeating.

An attempt that is not understood well enough to be reopened is deleted
rather than parked.
